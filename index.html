Mis PROYECTOS

JUEGO "100"

100 es un juego de dados desarrollado en C++, basado en estrategia y azar. El objetivo es alcanzar exactamente 100 puntos mediante diferentes tiradas de dados, tomando decisiones sobre cuándo continuar jugando y cuándo asegurar los puntos obtenidos. El proyecto fue desarrollado como parte de mi formación en programación, aplicando conceptos de programación orientada a objetos, estructuras de datos, funciones y lógica de programación.

Sistema gestor de un restaurante

Sistema desarrollado en C++ para administrar las principales operaciones de un restaurante. Permite gestionar clientes, mesas, mozos, platos, reservas y facturación, organizando y almacenando la información mediante archivos. El proyecto fue desarrollado aplicando programación orientada a objetos, manejo de archivos, clases y lógica de negocio.

Sistema gestor de artículos - WinForm

Aplicación de escritorio desarrollada en C# y Windows Forms para la gestión de artículos de un catálogo. Permite realizar operaciones ABM (alta, baja y modificación), búsqueda y consulta de detalles, trabajando con una base de datos SQL Server. El proyecto fue desarrollado aplicando conceptos de programación orientada a objetos, arquitectura por capas, acceso a datos, consultas SQL y manejo de interfaces gráficas.
